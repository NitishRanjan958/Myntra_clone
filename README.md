Myntra Clone 🛍️

This is a Myntra Clone website built using HTML, CSS, and JavaScript.
The project replicates the basic UI and functionality of the Myntra e-commerce platform.

🚀 Features

- Responsive homepage design
- Product listing section
- Navigation bar with categories
- Image banners and product cards
- Simple and clean UI

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

📌 Purpose

This project is created for learning and practice of front-end development.
